# 📊 Sales Analytics Dashboard

## 📌 Project Overview
This project presents an interactive Sales Analytics Dashboard built using Power BI and Tableau. The dashboard analyzes sales performance, profit trends, and regional contributions to help derive business insights.

---

## 🛠 Tools Used
- Power BI
- Tableau
- Excel (Data Cleaning)
- DAX Measures

---

## 📈 Key Insights
- Total Sales: ₹2.30M
- Total Profit: ₹0.29M
- West region contributes highest revenue
- Sales trend shows consistent growth from 2014–2017
- Higher discounts negatively impact profitability

---

## 📊 Dashboard Features
- KPI Cards (Total Sales & Total Profit)
- Regional Sales Bar Chart
- Sales Trend by Year Line Chart
- Interactive Filters
